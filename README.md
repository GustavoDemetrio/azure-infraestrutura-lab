Laboratório de Infraestrutura e Governança no Azure
Este repositório contém a documentação técnica, arquiteturas e resumos de laboratórios práticos focados em infraestrutura, segurança e governança no Microsoft Azure. O objetivo é servir como base de conhecimento (Knowledge Base) para implementações e boas práticas em ambientes cloud híbridos.

🎯 Objetivo
Documentar a aplicação prática de conceitos de cloud computing, desde o provisionamento de recursos até a governança e otimização de custos, servindo como portfólio de arquitetura e engenharia de infraestrutura.

📂 Estrutura do Conhecimento
1. Governança e Conformidade
Foco em padronização e controle de ambientes.

Implementação de Azure Policy para conformidade em escala.
Estratégias de Resource Locks para proteção de workloads críticos.
Uso de Tags para taxonomia e relatórios de cobrança (Cost Management).
Acessar Documentação de Governança
2. Segurança e Identidade (Microsoft Entra ID)
Gestão de acesso e proteção de ativos.

Diferença entre Autenticação e Autorização.
Configuração de RBAC (Role-Based Access Control) seguindo o princípio do menor privilégio.
Implementação de modelo Zero Trust e Defesa em Profundidade.
Acessar Documentação de Segurança
3. Computação e Rede
Arquitetura de máquinas virtuais e conectividade.

Provisionamento de VMs e VM Scale Sets para alta disponibilidade.
Configuração de regras de segurança (NSGs) e acesso RDP/SSH restrito.
Distribuição de carga com Azure Load Balancer.
Acessar Documentação de Computação
4. Armazenamento
Estratégias de armazenamento escalável e resiliente.

Definição de níveis de redundância (LRS, ZRS, GRS, GZRS).
Gerenciamento de ciclo de vida (Blob Hot/Cool Tiers).
Ferramentas de migração (AzCopy, Storage Explorer, Azure File Sync).
Acessar Documentação de Armazenamento
5. Monitoramento
Visibilidade e resposta proativa a incidentes.

Utilização do Azure Monitor e Log Analytics.
Diferença entre Azure Advisor, Service Health e Resource Health.
Acessar Documentação de Monitoramento
6. Gestão de Custos
Otimização financeira em nuvem (FinOps).

Uso de calculadoras de preços e TCO.
Configuração de orçamentos e alertas de cobrança.
Acessar Documentação de Custos
7. Gerenciamento e Implantação
Automação e Infraestrutura como Código (IaC).

Uso de Azure CLI, PowerShell e Cloud Shell.
Modelos ARM e Bicep para implantação declarativa.
Azure Arc para gestão híbrida.
Acessar Documentação de Gerenciamento
